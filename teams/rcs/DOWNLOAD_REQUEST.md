## Handling rules (proposed)
- Fetch by raw URL at the pinned commit (not `main`); verify each file's **git blob SHA-1** against the pinned tree
  before use. `manifest.json`'s `sha256` covers the **.qpy** only (checked: the d36 .qasm sha256 `e2e72760…` ≠
  manifest `2bb17672…`), so it cannot validate .qasm files.
- Request .qasm, not .qpy: our own line-grammar parser (`analysis/structure.py`, angles via `qasm_angle.angle`, no
  eval) handles them, and no qiskit deserializer is needed.
- `.npz` files are loaded only with `np.load(path, allow_pickle=False)` (arrays are uint64 bitstrings per data/README).
  Never unpickle.
- The .py files are listed so the team can READ the authors' estimator conventions (Eq. 1 normalisation, bit order);
  none of them is executed without a separate review.
- No outbound request carries identifying information (unauthenticated GET only).
